# Drum rudiments for my_rudiments.py
#
# Each example starts with its name in square brackets, followed by key: value lines.
#
#   [Name]            the rudiment's name (spoken and printed)
#   number: 16        optional; examples with the same number are grouped for --seamless
#   level: 1          1, 2 or 3 (or a list like 2,3); default 1
#   time: 4/4         optional; beats per bar over 4 (default 4/4)
#   bpm: 80           optional; tempo for this example (default: the file-wide bpm below)
#   pdf: ...          optional, rarely needed. With --pdf, examples are found in the PDF by
#                     their number and level. Use this to point somewhere else, e.g.
#                     'pdf: page 3, line 2' ('lines 4-5' for two lines, 'part 2' for the right-
#                     hand example on a shared line), or 'pdf: skip 13,30' to ignore noteheads
#                     that aren't struck (counting the example's notes from 1).
#   pattern: ...      the notes; may continue on the following indented lines
#
# Pattern codes (separate everything with spaces):
#   R  L        a stroke with the right / left hand
#   >           accent, written after the stroke:      R>
#   f           flam (grace note from the other hand):  fR  fL>
#   g           drag (two grace notes, other hand):     gR  gL>
#   ~           diddle (two strokes, same hand):        R~
#   z           buzz stroke:                            Rz
#   .           rest
#   @N          from here on, N notes per beat:  @1 quarters, @2 eighths, @3 eighth triplets,
#               @4 sixteenths, @6 sextuplets, @8 thirty-seconds
#   |           bar line (optional; bars are filled automatically)
#   |:  :|      repeat signs; the part between them is played twice
#
# Example:
#   [Single paradiddle]
#   number: 16
#   level: 1
#   bpm: 80
#   pattern: |: @4 R> L R R L> R L L R> L R R L> R L L :|
#
# Tempo: the "bpm:" line below sets the tempo for every example in this file.
# An example's own bpm: line overrides it, and --bpm on the command line overrides both.
